# Roxanne – Éditeur de texte en Rust

Roxanne est un projet d’éditeur de texte moderne, personnalisable et extrêmement performant, développé en **Rust** avec **Cargo**. L’objectif est de proposer une expérience fluide, légère en mémoire et efficace côté CPU, tout en restant extensible et modulable.

## Objectifs du projet
- **Performance** : faible consommation RAM et CPU au repos.
- **Personnalisation** : thèmes, raccourcis, configuration fine.
- **Extensibilité** : architecture modulaire et système de plugins.
- **Qualité** : stabilité, tests, documentation claire.

## Démarrage rapide (prévisionnel)
> Cette section sera enrichie au fur et à mesure que le projet avance.

1. Installer Rust (via `rustup`).
2. Cloner le dépôt.
3. Lancer les commandes Cargo (à définir).
