# Security Policy

## Signalement des vulnérabilités
Merci de signaler les vulnérabilités de sécurité de manière responsable.

- Email : **security@roxanne.local**
- Délai de réponse : nous accusons réception sous 72 heures ouvrées.

Merci d'inclure dans votre signalement :
- Une description claire de l'impact.
- Les étapes de reproduction.
- Les versions ou commits concernés.
- Toute preuve de concept utile.

## Politique de divulgation
Nous travaillons à corriger les problèmes signalés avant toute divulgation
publique. Nous vous tiendrons informé de la progression et des délais.

## Portée
Cette politique couvre le code source, la documentation et les scripts de ce
référentiel.
