# UI – Interactions et composants

## Principes UX
- Flux clavier prioritaire.
- Actions rapides, feedback immédiat.
- Interactions prévisibles et cohérentes.

## Composants prévus
- Barre de statut (fichier, position, mode).
- Zone d’édition principale.
- Panneau de recherche avancée (options, résultats).
- Palette de commandes (future).

## Entrées utilisateur
- Clavier : navigation, édition, commandes.
- Souris : sélection, positionnement du curseur.

## Recherche avancée (Phase 2)
- Bascule regex et casse dans l’UI.
- Sélecteur de portée (fichier courant / workspace).
- Liste scrollable des résultats avec aperçu.

## Accessibilité
- Contraste élevé par défaut.
- Taille de police configurable.

## Planification UI
- Phase 1 : navigation clavier, barre de statut, recherche simple.
- Phase 2 : panneau de recherche avancée et surlignages.
- Phase 3 : palette de commandes et personnalisation des raccourcis.
